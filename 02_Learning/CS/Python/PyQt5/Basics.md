**Инструкция:** На основе папки C++ в моем хранилище вот несколько учебных задач, которые проверят ваши знания. Пожалуйста, не выходите за рамки этих задач.

1. Напишите программу, которая демонстрирует использование классов и объектов, включая конструкторы, деструкторы и инкапсуляцию.
2. Реализуйте пользовательский контейнер с использованием шаблонов и модели аллокатора STL.
3. Напишите функцию, которая использует умные указатели (`unique_ptr`, `shared_ptr`), чтобы управлять динамической памятью и избежать утечек.
4. Создайте программу, которая использует лямбда-функции и обертку `std::function` для реализации простого механизма обратного вызова.
5. Разработайте многопоточную программу с использованием `std::thread` и `std::mutex` для безопасного обмена данными между потоками.
